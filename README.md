# markz-social-assets

Host público, único propósito: servir as imagens dos carrosséis da Markz Imports
via jsDelivr antes/durante a publicação automática no Instagram e Facebook
(`scripts/postar-instagram.js` e `scripts/postar-facebook.js` no repositório principal).

Estrutura: `img/posts/<slug>/<arquivo>.png`

URL pública de cada arquivo:
`https://cdn.jsdelivr.net/gh/victormarcolino0-dev/markz-social-assets@main/img/posts/<slug>/<arquivo>.png`

Não contém nenhuma credencial, dado de negócio ou conteúdo não-destinado-a-ser-público —
tudo aqui é, por definição, o que está prestes a ser postado publicamente de qualquer forma.
